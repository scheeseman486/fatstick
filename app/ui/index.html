~~~~~~~~~~~~~~ NO PLAYLIST
~~~ --- TRK

Open a playlist, pick a stick, copy, then lock the order.

No playlist

M3U, M3U8, XSPF (VLC) and PLS playlists work.

    Open a playlist to start, or drop the file on this window.

    Drag tracks to change the order, or select one and press Alt+↑ / Alt+↓.

    USB stick

    1. Copy in order

      Copies one file at a time into a fresh folder. No password needed.

    2. Lock the order

      Rewrites the folder's entry table so every player follows the playlist. Your system asks for your password or fingerprint.
